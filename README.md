# Nails Gallery — публикация на FirstVDS

Статус: сценарий подготовлен, но ещё не подключён к GitHub и серверу.

Содержимое этой папки предназначено для отдельного закрытого репозитория.
Папка `site` содержит страницу, фотографии, новый логотип и favicon.
После настройки отправка изменений в `main` запускает публикацию.
Ручной запуск: Actions → Publish Nails Gallery → Run workflow.

## Однократная настройка

1. Создать или выбрать репозиторий и загрузить содержимое этой папки, включая `.github`.
2. Создать отдельный SSH-ключ для GitHub Actions и добавить публичную часть в
   `/home/deploy_nails/.ssh/authorized_keys` на FirstVDS. Личный ключ Windows не переносить.
3. Добавить приватную часть отдельного ключа в Actions secret `DEPLOY_SSH_KEY`.
4. Добавить проверенную запись ключа SSH-сервера для `94.250.255.207` в secret
   `DEPLOY_KNOWN_HOSTS`. Использовать запись из уже доверенного подключения
   или сверить отпечаток через консоль FirstVDS; одного непроверенного ssh-keyscan недостаточно.
5. Запустить первый деплой и проверить успешное завершение и сайт.

Сценарий использует SSH-порт 22, пользователя `deploy_nails` и только каталог
`/var/www/artnails/data/www/nailsgallery.ru`. Эти параметры необходимо подтвердить
при настройке подключения. Из Windows они не считываются.

## Публикация

Изображения загружаются в новую папку для каждого запуска. Для папок задаются
права 755, для файлов 644. До замены страницы проверяются все изображения
по HTTPS и сравниваются их байты. Предыдущая страница сохраняется вне публичного
каталога в `/home/deploy_nails/nailsgallery-backups/`.
После замены проверяется точное содержимое страницы по HTTPS.
При ошибке этой проверки сценарий пытается восстановить предыдущую страницу,
но не перезаписывает её, если за это время кто-то опубликовал другую версию.

Публикации GitHub выполняются последовательно. Не запускайте одновременно
старый ручной деплой Windows. Старые папки изображений и резервные копии
не удаляются автоматически.

## Локальная проверка

`python scripts/deploy.py --check`

Ключи не хранить в репозитории. GitHub Actions использует Secrets.
